# Writing Documentation

Khi user yêu cầu viết README hoặc docs:

## Structure
1. **Title** + 1-line description
2. **Tech stack** badges
3. **Quick start** (install, run, test)
4. **Project structure** (tree)
5. **Features** list
6. **Scripts** table
7. **Contributing**
8. **License**

## Style
- Use emoji for sections (📁 📦 🚀 ⚙️)
- Code blocks with language tags
- Tables for command lists
- Keep it scannable (lots of headings)
- Examples > abstract descriptions

## For API docs
- Endpoint URL
- Method (GET/POST/etc)
- Auth required?
- Request body schema
- Response schema
- Error codes
- cURL example
